# Online Store iOS App 

A simple and user-friendly e-commerce iOS application. This repository represents one of my very first projects in learning iOS development using Swift. It demonstrates fundamental mobile app concepts and backend integration.

##  Features
* **User Authentication:** Secure Login and Registration using Firebase Auth.
* **Profile Management:** Update account details, change passwords, and manage user settings.
* **Shopping Cart:** Add products to the cart and view the total dynamic price.
* **Checkout Flow:** A complete order placement system that saves delivery details directly to the database.
* **Order History:** Fetch and display previous orders in a clean, scrollable interface.

## 🛠 Tech Stack
* **Language:** Swift
* **UI Framework:** UIKit (Storyboard)
* **Architecture:** MVC (Model-View-Controller)
* **Backend:** Firebase (Authentication & Firestore)
